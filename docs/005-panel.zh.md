# 005 面板

[English](005-panel.md) | 中文

在 DeepSeek Harness Web 侧栏打开 **Superagent**，即可监督 agent（智能体）。面板优先显示需要人的工作，其次是系统健康和历史。本文以 [000 理念](000-philosophy.zh.md)至 [004 提示词](004-prompts.zh.md)为基础。

## 三个问题

打开面板后，按顺序回答三个问题：

1. 现在有什么需要我处理？
2. 系统是否健康，是否在做正确的事？
3. 某项工作从触发、评估到工单的完整历史是什么？

## 标签页

标签页按工作流排列：**概览**、**来源**、**触发**、**评估**、**执行**和**设置**。仓库及账号设置成功前，概览显示缺失项，并链接到对应设置。

| 标签页 | 显示内容 |
| --- | --- |
| 概览 | 需要操作的工单、系统问题、最近 24 小时活动计数及执行器负载。每块链接到详细页面 |
| 来源 | 来源状态、设置问题及非零计数。被过滤触发和被丢弃消息与概览使用相同的 24 小时时间窗口 |
| 触发 | 按已订阅、评估中、24 小时内有新触发或所有线程筛选线程。各线程按最新优先显示触发，以及决定和订阅 |
| 评估 | 决定及其原因和匹配规则 |
| 执行 | 执行器状态、暂停处理，以及按未结束、待处理、执行中、等待触发或已结束筛选的工单。工单详情显示操作、授权、等待输入、订阅和派工 |
| 设置 | 来源、评估、执行、提示词和部署。各组包含保存历史 |

### 阅读单条记录

被丢弃消息链接到所属工单；没有工单时链接到线程。来源页面说明是对话消失，还是来源停止监听。

仍归执行器处理的人工后续消息标记为**已送达工单**，不产生评估。线程还显示退回原因及仅用于上下文的订阅。**重新评估**可以将该后续消息送往评估，也可以重试没有有效判断的触发：被来源过滤的触发、未完成评估，或既没有非停止决定、也没有执行器确认的已投递消息。

工单详情显示起始触发、决定及原因、范围和策略版本。派工及次要详情折叠在即时操作下方。输入投递失败，或受阻、失败报告后等待人工的工单提供**重试**。已结束工单显示 **PR 已合并**或**人工停止**等结果。

## 设置分组

- **来源：** 每个来源一张卡片，包含开关、字段和已验证账号事实。GitHub 还提供新 Issue、PR（Pull Request）、评论及默认分支 CI 的全部接收开关。轮询和读取限制位于高级设置。
- **评估：** 策略版本和规则，随后是**各来源**及评估设置。每个来源标签页包含允许名单、成员同步、准入表和机器人名单。同步在启动时及点击**立即同步**时运行。准入表区分接收范围、发送者是否在名单中，以及消息是否直接向 agent 发出。评估设置选择接单模式、超时及研判模型。
- **执行：** worker 模型、并发、目录根路径、准备命令和禁止命令。点击可用变量将其插入准备命令。
- **提示词：** **编辑**修改团队部分、内置部分和 skill（技能）。**完整提示词**显示组装文本，并与已保存文本或默认值比较。**历史**列出版本。已编辑的内置部分标记为已修改，可以重置；模板列出必需占位符。

  升级改变被覆盖的默认内容时，标记为**默认内容已更新**（Default updated）。面板在团队文本上方比较新旧默认值。未记录旧默认值时，改为比较团队文本与新默认值。选择**保留我的文本**或**使用新默认值**。已移除部分的覆盖列在标签栏下方，并在下次保存时丢弃。
- **部署：** 启动问题及**重新检查**、状态目录和机器限制。保存的限制无需重启即生效。DeepSeek Harness 插件管理器提供相同页面。

## 搜索

页头搜索按文本、id、飞书消息 id 或存储的链接查找触发，例如 GitHub 评论 URL。原消息中缺失的飞书链接，只有宿主在当前进程生命周期内读取后才可搜索。

搜索也通过 `#12` 或 GitHub URL 等引用查找线程，并按标题或匹配线程查找工单。

## 原则

1. **关注重要事项。** 每个元素必须回答三个问题之一，否则移除。数字只有在影响监督者行动时才显示。
2. **定义精确。** 分类有可检查的定义，互斥且覆盖所有情况，如工单阶段。标签说明该行在等谁、需要什么，不显示内部状态码。
3. **每个概念一个位置。** 来源状态放在来源，线程和触发放在触发，决定放在评估，工单放在执行。设置按所配置的概念分组。概览总结这些页面并链接到它们，不成为另一份详细视图。
4. **领域结构。** 面板使用领域术语。内部标识只出现在折叠详情中，能解析名称时用名称替代标识。
5. **如实显示状态。** 计数等于其链接列表的长度，任何状态都不与其他事实矛盾。
6. **默认安静。** 健康状态不占额外空间。问题必须可操作，单次网络错误还不够。需要人的行直接提供操作。页面说明限制为一句话，进一步解释放入 (?) 提示。破坏性操作需要确认。
7. **控件一致。** 使用 DeepSeek Harness 的设计 token 和控件行为。同一信息在整个面板中应外观一致。每个设置块只有一个保存栏，仅在有改动、正在保存或保存失败时显示。
